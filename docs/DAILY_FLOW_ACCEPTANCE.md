## 人工验收入口与步骤（复测参考）

准备好的文件夹：仓库 `.scratch/issue69-current/manual/`。
双击 `Hub.lnk` 打开本轮固定构建。`New PowerShell.lnk` 新建终端，
`Open Independent.lnk` 打开默认独立字符映射表，`Open Managed.lnk` 打开显式受管控制台。
`External Character Map.lnk` 用于先在 Hub 外启动字符映射表。
这些入口使用短暂隐藏的 PowerShell wrapper 注入私有数据根，不是正式安装入口；图标引用本轮 Hub。
构建哈希发生变化时入口会拒绝启动，不能把后续构建结果混进本轮。
已打开一个测试 Hub 供用户操作，字符映射表和受管控制台待用户按步骤启动。
配置只在本私有文件夹内保存；人工入口显式显示 Hub 窗口，隐藏 wrapper 不决定 Hub 的窗口状态。

1. **窗口、输入与图标**：打开 Hub，确认只有一层深色标题栏；拖动、双击最大化/还原、
   四边缩放和 Windows 贴靠正常。检查任务栏、托盘、临时快捷方式图标一致。
   双击 `New PowerShell.lnk` 两次，切换两终端、缩放后分别输入 `Write-Output 'manual69-ok'`，
   确认两处都能执行且先前输出保留。正式日常入口单独检查并报告它对应哪个构建。
2. **托盘隐藏**：在一个终端执行 `1..10 | ForEach-Object { $_; Start-Sleep 1 }`，
   点窗口关闭后从托盘图标恢复，确认输出继续、能再输入；也验证最小化后从入口恢复。
3. **独立与受管退出**：用两个 `Open…` 入口分别打开字符映射表和标题为 `LCH69-Managed`
   的控制台。托盘“停止全部”应保留字符映射表、结束受管控制台。再打开受管控制台并创建
   未保存终端，托盘真正“退出”后字符映射表仍活着、受管控制台消失；重开 Hub 不恢复未保存终端。
   最后自行关闭这次测试打开的字符映射表。
4. **外部窗口与实际启动器**：先退出测试 Hub 并关闭测试字符映射表，再双击
   `External Character Map.lnk`，然后 `Open Independent.lnk`；应复用已有窗口、没有第二份。
   用户实际秋叶/ComfyUI 启动器按同样路径验证；添加时检查显示模式推荐可改，不重复内嵌。
   模糊身份应给出选择，取消不改变已有进程。窗口无法被 Windows 唤起时应反馈真实原因，不能另开补救。
5. **额外环境**：在没有 PowerShell 7 的 Windows 机器/VM 上使用该版本的正式构建，
   从应用及带空格/Unicode 目录入口新建终端，执行 `$PSVersionTable.PSVersion` 与 `(Get-Location).Path`。
   应为 Windows PowerShell 5.1 和指定目录。权限/不可启动 shell、真实并发保存冲突及
   Starting/Stopping 瞬态入口验证分别报告，未制造出目标条件时标未运行。
