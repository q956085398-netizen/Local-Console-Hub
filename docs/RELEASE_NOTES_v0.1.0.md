# Local Console Hub v0.1.0 — 初版发布说明

更新：2026-10-02。Windows x64 初版，日常流程与添加应用流程已获用户确认。安装包本轮验证范围单独记录于 [交付记录](acceptance/2026-10-02-v0.1.0/DELIVERY.md)，不把历史测试迁移为当前安装包验收。

## 安装与使用

从 [发布页](https://github.com/q956085398-netizen/Local-Console-Hub/releases/tag/v0.1.0) 下载 EXE（当前用户）或 MSI（所有用户，需要管理员）。

完整步骤见 [安装与使用教程](USER_GUIDE.md)。第一次打开可先新建 PowerShell，再添加常用应用；无需手动编写配置即可开始使用。

## 初版提供的功能

- 真实 ConPTY 交互终端：新建、输入、Ctrl+C、缩放、切换保留输出。
- 图形化添加应用，选择目录/程序/日志文件；有限范围查找启动候选并预填名称、命令和可识别端口。
- Hub 内部显示或独立窗口；独立生命周期与显式受管生命周期分开选择。
- 已保存应用启动、复用、停止与重启；只操作所属进程树。
- 识别在 Hub 外运行的实例，提供关联或选择；关联外部进程不自动转为受管。
- 临时终端保存启动配置；停止后移除应用名单，保留应用文件与磁盘日志。
- 单实例恢复、终端快捷方式、已保存应用的 `--open-app` 入口。
- 主窗口关闭隐藏到托盘；真正退出有独立入口。
- 按需捕获日志、关联自有日志与运行历史；普通交互终端默认不落盘，输入不持久化。
- 配置端口的本机 TCP 可达性信号和网页入口。

## 数据、升级与卸载

配置：`%APPDATA%\LocalConsoleHub\config.yaml`。日志/历史：`%LOCALAPPDATA%\LocalConsoleHub\`。这些目录与安装目录分开。

升级前从托盘退出 Hub、备份数据，再运行新包；当前没有自动更新。卸载保留配置与日志；EXE 卸载复选框只删除 `%LOCALAPPDATA%\com.localconsolehub.hub\` 浏览器配置，不删除 Hub YAML 或日志。详见教程。

## 已知限制

1. 安装包未签名，Windows 可能提示未知发布者；核对下载来源与 SHA-256 后决定是否运行。
2. 仅 Windows x64。缺少 WebView2 时需联网获取运行时；安装向导为英文。
3. 配置端口 TCP 可达不等于 HTTP 健康，也不证明监听者属于当前会话；系统端口监视列入下一版。
4. 服务输出为只读缓冲，需要键盘输入时使用交互终端。独立窗口不提供 Hub 内部捕获输出。
5. 目录识别范围有限，候选需用户确认；识别不执行程序，也不安装依赖。
6. 关联外部窗口受进程身份、权限和 Windows 前台切换规则限制；无法确认时不盲目复用或结束。
7. 配置路径为字面量，不展开环境变量或 `~`；复杂或损坏的 YAML 不支持安全自动编辑时会拒绝写入。
8. 本轮不声称 MSI 实际安装、所有机器上的升级、所有原生视觉项目均已验证；详见交付记录和历史 [安装验收](RELEASE.md)。
