# Local Console Hub v0.2.0 — 查看端口并在确认后结束占用者

更新：2026-10-04。Windows x64。

这一版可以查看本机哪些端口正在被占用，并在需要时结束那个占用者。不会因为端口被占用就自动结束进程，也不是全系统进程管理器。

- 端口页列出协议、地址、端口，以及能读到的进程名、PID 和程序路径。TCP 与 UDP 分开。读不到时显示信息不可用。
- 占用者按受管会话、外部和信息不可用来分组。外部默认收起。会话分组也可以折叠。
- 启动一个配置了端口、当前没在运行的会话时，如果端口已被占用，会先显示占用者。取消则不启动，也不结束对方。
- 确认结束前会再次核对进程。已经退出，或者这个 PID 已经换成了别的进程，就不会结束它。受管会话的进程请用该会话自己的停止。
- 配置了 http(s) 地址的会话另有一次 HTTP 结果，不改写原来的 TCP 可达。详情里可以看到本会话的 CPU 占比和工作集。

侧栏底部的「新建 PowerShell」和「添加应用」排在同一行。

## 安装

从 [v0.2.0 发布页](https://github.com/q956085398-netizen/Local-Console-Hub/releases/tag/v0.2.0) 下载 EXE 或 MSI。已有版本先从托盘退出，再安装。升级保留已有应用配置，不会自动清除用户数据。

详细步骤见 [安装与使用教程](USER_GUIDE.md)。v0.1.0 与 v0.1.1 的说明保留，不在这里重写。

自动结束占用者和全系统进程管理仍未做，见 [尚未纳入的部分](NEXT_VERSION.md)。
