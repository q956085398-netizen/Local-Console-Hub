# 下一版计划：端口监视

更新：2026-10-02。目标版本 v0.2.0，尚未实现，不承诺发布日期。

初版已针对运行中服务的配置端口，约每 5 秒检查 `127.0.0.1` TCP 可达性。下一版补充监听端口与占用进程，让用户知道“哪个程序占用了这个端口”。TCP 可达性不等于 HTTP 服务健康。

| 准备更新 | 预期效果 |
| --- | --- |
| 本机监听端口列表 | 展示协议、监听地址和端口；优先 TCP，UDP 单独说明语义 |
| 占用进程 | PID、进程名、可取得的程序路径；权限不足时显示信息不可用 |
| 关联受管会话 | 核实进程身份及所属树后关联；其它标为外部，不仅凭端口推定归属 |
| 启动前冲突提示 | 端口已占用时展示占用者与详情，提示用户处理，不自动结束进程 |
| 变化与刷新 | 监听新增/消失、占用者变化、最近检查时间；手动与低频自动刷新 |
| 查找与定位 | 按端口/进程/会话查找，跳到对应受管会话 |

## 完成标准

1. 真实 Windows 程序打开/关闭端口后，在刷新周期内反映变化；验证 TCP/UDP 与 IPv4/IPv6。
2. 端口占用、进程退出及 PID 复用时归属准确；无法取得信息时显示未知或权限不足。
3. 外部程序占用配置端口时有具体冲突提示，不误停外部或其它会话。
4. 展示最后检查时间、刷新中与失败状态；窗口隐藏时降低或暂停可视列表轮询，不用旧数据冒充实时。
5. 基础查看不要求管理员权限；额外权限字段有清楚提示。
6. 完成真实 Windows 端口/进程取证和回归，模拟数据不替代原生验证。

本轮只确定计划。HTTP 健康探测、资源监视、全局进程管理与自动结束占用者另行评估。
