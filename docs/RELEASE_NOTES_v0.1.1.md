# Local Console Hub v0.1.1 — 首次使用修正

更新：2026-10-02。Windows x64 修正版。

没有配置或没有会话时，启动直接进入正常主界面：左侧保留搜索、加号、“新建 PowerShell”和“添加应用”，右侧没有虚假的终端或标签。无需先创建会话才能进入，也无需添加应用后重启。

首次使用说明明确指向左下方按钮。缺少配置文件或合法空配置不再显示警告；真正的配置错误仍显示诊断。添加的应用立即出现并在下次启动保留，临时终端只有主动保存启动配置后才会保留。

## 安装

从 [v0.1.1 发布页](https://github.com/q956085398-netizen/Local-Console-Hub/releases/tag/v0.1.1) 下载 EXE 或 MSI。已有版本先从托盘退出，再安装修正版。升级保留已有应用配置，不会自动清除用户数据。全新安装没有预置示例会话。

详细步骤见 [安装与使用教程](USER_GUIDE.md)。初版功能与限制见 [v0.1.0 发布说明](RELEASE_NOTES_v0.1.0.md)。
