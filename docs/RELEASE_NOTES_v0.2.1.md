# Local Console Hub v0.2.1 — 修复服务重启并简化终端操作

更新：2026-10-06。Windows x64。

- 修复 GUI 启动的 Hub 在停止服务后再次启动或重启时出现“句柄无效（os error 6）”的问题。
- 取消会话右上角的三点菜单。临时终端使用直接的 **关闭** 按钮，先结束所属进程树再移除；停止或移除失败会保留列表项并提示。**停止** 仍保留会话及输出。
- 已保存的应用使用直接的 **移除** 按钮，沿用确认弹窗；只移除 Hub 启动配置，不删除应用文件或磁盘日志。
- **保存启动配置** 移到临时终端的 **详情** 页。新建终端仍自动获得输入焦点。
- 新建 PowerShell 复用最小空闲编号；全部关闭后再新建，从 `PowerShell 1` 开始。现有终端不改名，每个新会话仍有独立身份。
- 修正 Windows 测试辅助进程的启动等待与清理顺序，避免过早结束 shell 或遗留测试子进程。

## 安装

从 [v0.2.1 发布页](https://github.com/q956085398-netizen/Local-Console-Hub/releases/tag/v0.2.1) 下载 EXE（当前用户安装）或 MSI（所有用户安装，需要管理员权限），选择一个。

已有版本先通过托盘菜单 **退出**，再安装；只关闭主窗口会继续在后台运行。建议继续使用原来的安装包类型和目录，并先备份配置与日志。

[安装与使用教程](USER_GUIDE.md) · [尚未纳入的部分](NEXT_VERSION.md)。v0.2.0 的端口功能和历史说明保留。

## 验证与已知限制

前端 356 项测试和 30 项真实 Tauri/WebView2/IPC 验收通过，用户配置未改变，验收场景清理全部通过。服务重启回归通过实际 GUI 入口运行私有批处理夹具；本轮没有直接启动用户的 SillyTavern。Rust 套件的时序失败及单独重跑结果见 [本地验收记录](acceptance/2026-10-06-v0.2.1/README.md)。

正式 EXE 与 MSI 使用默认生产特性打包，文件版本为 `0.2.1`。本轮没有执行新安装包的安装、覆盖升级或卸载验收。安装包未签名，缺少 WebView2 时需联网获取运行时；发布附件提供 SHA-256 校验值。
