# 添加应用流程改进与验收

更新：2026-10-02。源码修改留在本地，未提交或发布。

## 已实现

- 工作目录旁增加 Windows 目录选择按钮；启动命令旁可选择程序或脚本，关联日志也可选择文件。
- 选择目录后查找 `.exe`、`.bat`、`.cmd`、`.ps1`，最多扫描两层子目录、600 个目录项和 30 个候选。跳过常见依赖、模型目录以及越出所选目录的链接，不执行候选程序。
- 唯一候选可预填名称、启动命令及工作目录；多个候选由用户选择。脚本中唯一的明确 `--port` 参数作为待确认的端口提示；找到唯一日志文件时预填日志路径。手动编辑过的字段不会被扫描结果覆盖，明确选择某个启动文件时则更新命令与工作目录。
- 网页地址默认选用 `http://`，可切换 `https://`，也支持粘贴完整地址。填写端口后补齐 `127.0.0.1:端口`；手动改过地址后不再随端口覆盖。空地址仍是可选项。
- 下拉菜单使用深色主题和不透明深色选项背景，避免浅色文字叠在系统白色弹层上。
