# Local Console Hub v0.2.0 安装与使用教程

适用：Windows x64。使用安装版无需安装 Node.js、Rust 或下载仓库源码。

## 1. 下载和安装

打开 [v0.2.0 发布页](https://github.com/q956085398-netizen/Local-Console-Hub/releases/tag/v0.2.0)，下载一个安装包：

| 文件后缀 | 安装范围 | 默认目录 | 权限 |
| --- | --- | --- | --- |
| `x64-setup.exe` | 当前用户，日常使用 | `%LOCALAPPDATA%\Local Console Hub` | 通常无需管理员 |
| `x64_en-US.msi` | 所有用户 | `C:\Program Files\Local Console Hub` | 需要管理员 |

两个包为同一版本，选择其中一个。GitHub 可能把附件文件名中的空格替换为点。

1. 如果旧 Hub 在托盘中运行，先使用托盘菜单 **退出**；只关闭主窗口会留在后台。
2. 已有配置时先备份 `%APPDATA%\LocalConsoleHub`；需要保留日志时也备份 `%LOCALAPPDATA%\LocalConsoleHub`。
3. 下载 `SHA256SUMS.txt`，在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 -LiteralPath '安装包完整路径'`，与对应文件校验值比较。
4. 双击安装包，按英文向导完成安装，再从开始菜单打开 **Local Console Hub**。

包未使用代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。确认来自本项目发布页、校验值一致且愿意信任程序时，可通过“更多信息 → 仍要运行”继续。组织策略禁止运行时遵守机器策略。

需要 Microsoft Edge WebView2 Runtime；缺少时安装器会联网下载。离线机器应先准备 WebView2。

## 2. 第一次使用：试一个终端

首次打开直接进入完整主界面：左侧会话列表为空，右侧没有终端。无需先添加应用或创建终端，左侧搜索与底部的两个入口始终可用。

1. 点击左下方 **新建 PowerShell**（左侧顶部的 **+** 也可以）。这是可选操作，保持空界面同样可以使用。
2. 输入 `Get-Date` 并回车，应看到时间输出。
3. 再新建一个终端，切换两者，之前的输出保留。
4. 长命令可按 Ctrl+C 中断；它不等于关闭整个 Hub。
5. 临时终端默认不写磁盘日志，也不自动保存到下次启动。

优先使用已安装的 PowerShell 7；没有时使用 Windows PowerShell。想保留 shell 与工作目录，在更多操作中选择 **保存启动配置**。保存只保留启动方式，不保存或重放输入。

## 3. 添加常用应用

以 ComfyUI、SillyTavern 或本地 API 为例：

1. 点左下方 **添加应用**，填写可识别的名称。
2. 选择实际应用目录。Hub 会有限范围查找 `.exe`、`.bat`、`.cmd`、`.ps1` 候选，不会执行它们。
3. 多个候选时选择平时真正使用的入口；也可用 **选择文件** 指定程序或脚本。检查自动填入的命令与工作目录。
4. 需要额外参数时补入完整命令。路径含空格应加双引号，例如 `"D:\AI Tools\ComfyUI\run.bat"`。
5. 选择展示方式和生命周期，见下一节。
6. 网页服务可填写端口及地址。例如填 `8188` 后，未手动编辑的地址会补为 `127.0.0.1:8188`；默认 HTTP，也可选 HTTPS。以实际程序为准，识别出的端口只是待确认提示。
7. 选日志策略，可填写用途与关闭影响，点击保存。
8. 保存成功后立即出现在左侧，无需重启；下次打开仍会保留。选中并 **启动**；有地址时可 **打开网页**。

启动失败时核对目录、命令、依赖与程序自身错误。Hub 不会替应用安装 Python、Node.js、模型或其它依赖。扫描范围有限，找不到入口时可以手动指定。

## 4. 展示方式和生命周期

| 选择 | 适用情况 | 停止或退出 |
| --- | --- | --- |
| Hub 内部 | 输出集中在 Hub 的本地服务 | Hub 管理所属进程树 |
| 独立窗口 + 独立生命周期 | 自带控制台或窗口的启动器 | Hub 退出后可以继续；在自己的窗口结束它 |
| 独立窗口 + Hub 受管生命周期 | 保留独立窗口，同时让 Hub 管理启停 | Hub 停止/退出可以结束所属进程树 |

推荐结果可手动修改。独立窗口不捕获 Hub 内部输出，可不记录或关联自有日志。服务输出通常只读；需要键盘交互时使用交互终端。

应用已在 Hub 外运行时，会尝试识别可关联实例；有多个或不确定候选时按提示选择。关联不等于接管，外部进程不会因退出 Hub 被自动终止。无法唤起窗口时会显示原因。

## 5. 日常操作

- **启动 / 停止 / 重启**：对选中会话生效。停止优先正常结束，必要时结束所属进程树；操作前查看关闭影响。
- **Terminal / Logs / Details**：查看当前输出、日志与启动详情。显示缓冲和磁盘日志是不同内容。
- **从受管名单移除**：先停止应用，独立应用先在自己的窗口退出，再从更多操作移除并确认。只删除启动配置与名单记录，应用文件和磁盘日志保留。
- **移除临时终端**：已结束临时项可移除；未保存项下次启动不会恢复。
- **关闭主窗口**：隐藏到托盘，会话继续运行。
- **恢复窗口**：用托盘或再次从开始菜单打开，同一个 Windows 登录会话只保留一个 Hub。
- **真正退出**：托盘菜单 **退出**；运行中受管项提示确认，独立应用与关联外部进程保留各自生命周期。

会中断生成任务、下载或其它工作时，应先确认程序当前任务，再停止。

## 6. 查看占用的端口

左侧切到端口页，可以看到本机正在监听的端口，以及占用它的进程名、PID 和能读到的程序路径。列表分成受管、外部和信息不可用。外部默认收起。读不到的字段显示信息不可用，不是 0。

需要结束某个占用者时，在对应行确认。Hub 会再次核对这个进程；已经退出，或者这个 PID 已经换成了别的进程，就不会结束它。受管会话的进程不从这里停止，用该会话自己的停止。Hub 不会因为端口被占用就自动结束进程。

启动一个配置了端口、当前没在运行的会话时，如果该端口已被占用，会先显示占用者。取消则不启动，也不会结束对方。

## 7. 日志与配置

添加应用可选不记录、出错时记录、持续记录、手动记录或关联已有日志；未指定项按展示方式的默认策略处理。用户输入不持久化，普通交互终端默认只有内存缓冲。关联外部日志只建立入口，不复制原文件。

| 数据 | 路径 |
| --- | --- |
| 配置 | `%APPDATA%\LocalConsoleHub\config.yaml` |
| 捕获日志 | `%LOCALAPPDATA%\LocalConsoleHub\logs\` |
| 运行历史元数据 | `%LOCALAPPDATA%\LocalConsoleHub\metadata\` |
| Hub 缓存 | `%LOCALAPPDATA%\LocalConsoleHub\cache\` |
| WebView2 浏览器配置 | `%LOCALAPPDATA%\com.localconsolehub.hub\` |

可在资源管理器地址栏粘贴这些路径。日志页提供打开文件、目录和清理入口，清理前看清范围。

图形界面支持添加、保存和移除配置。若需要手动改 YAML，先退出 Hub、备份文件，再编辑并重开。路径为完整字面路径，不展开 `%VAR%`、`$env:…` 或 `~`；YAML 中 Windows 路径建议单引号，例如 `cwd: 'D:\AI Tools\ComfyUI'`。

## 8. 可选：创建快捷方式

新建 Windows 快捷方式，目标指向安装目录的 `local-console-hub.exe`，再加参数。

新建终端：

```text
"C:\完整安装路径\local-console-hub.exe" --new-terminal --directory "D:\Work"
```

打开已保存应用：

```text
"C:\完整安装路径\local-console-hub.exe" --open-app comfyui
```

把 `comfyui` 替换成配置中的实际 `id`，不是显示名称或启动命令。已运行时复用对应会话。创建独立的 Hub 入口即可，不替换系统 PowerShell 全局入口。

## 9. 升级、卸载与排障

升级前从托盘退出、备份数据，再运行新包。当前没有自动更新，建议继续用同一种包与原目录。

卸载使用 Windows“已安装的应用”或安装目录卸载程序。配置、日志与运行历史保留。EXE 卸载的 **Delete WebView2 browser profile (not your config or logs)** 仅清理浏览器配置。彻底删除个人数据前，先确认备份，再自行删除上表相应目录。

| 问题 | 处理 |
| --- | --- |
| 关窗口后服务还在跑 | 托盘常驻是预期行为；停止对应会话或真正退出 |
| 安装新包后仍看到旧界面 | 旧 Hub 可能在托盘；退出旧实例，再从新入口打开 |
| 端口显示可达但网页打不开 | TCP 可达不证明 HTTP 健康；核对日志、地址和启动状态 |
| 无法移除应用 | 先结束其进程；配置损坏、写入失败或无法安全编辑时也会保留原名单并提示 |
| 服务终端不能输入 | 服务为只读缓冲，需要交互时使用终端会话 |
| 没有日志文件 | 检查不记录/出错时记录策略，或独立窗口未捕获输出 |

自动结束占用者和全系统进程管理不在这一版，见 [尚未纳入的部分](NEXT_VERSION.md)。v0.1.0 与 v0.1.1 的历史说明仍保留。
